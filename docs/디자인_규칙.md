# 디자인 규칙 — meeting_v

> 화면을 만들거나 고칠 때 읽는다. 값은 여기에 옮겨 적지 않고 정본 파일을 가리킨다.
> 점검은 `ui-reviewer` 에이전트와 `python .claude/tools/design_check.py`가 한다.

정한 것 (2026-11-13, 흰 사이드바 안 B 선택)
- 주 색은 `tokens.css` 값 `--accent #0963c4`. `v2m.css`의 `#0a6cd6`은 쓰지 않는다.
- 사이드바는 네이비가 아니라 흰색. 시안 v2m의 네이비 사이드바와 남색 제목은 따르지 않는다.
  - `--side-bg #ffffff`, `--side-fg #111114`, `--side-muted #48484d`, 오른쪽 경계선 `--sep`
  - 지금 메뉴: 바탕 `--accent-soft`, 글자 `--accent-ink`, 왼쪽 막대 `--accent`
  - 큰 제목(h1)은 `--fg`
- `tokens.css`는 원본이라 이 묶음에서 고치지 않았다. S0(골격)에서 앱 CSS를 만들 때 위 값으로 바꾸고, 바꾼 내용을 변경 이력에 적는다.

## 2. 규칙

1. 색·크기는 토큰 변수로만 쓴다. hex·rgb 값을 직접 쓸 수 있는 곳은 `tokens.css`와 `.streamlit/config.toml`(테마 지정)뿐이다.
2. 의미 색은 뜻으로만 쓴다. `--share` 공유 정보, `--danger` 문제·빈 필수 칸, `--signal` 이슈·확인 필요·발행 뒤 바뀜, `--accent` 주 동작·대기 중인 일, `--ok` 종결·완료, `--decide` 결정. 장식에 쓰지 않는다. `--anno`는 시안 메모 전용이라 앱에 쓰지 않는다.
3. 이모지를 쓰지 않는다. `✓ ✔ ⚠ ★ ●` 같은 기호 문자도 상태 표시에 쓰지 않고 아이콘으로 바꾼다 (시안의 `✓`, `🖼`도 구현 때 아이콘으로).
4. 아이콘은 Streamlit Material 아이콘 한 벌(`:material/이름:`, 버튼의 `icon=`)만 쓴다. 같은 뜻에는 같은 아이콘, 아이콘만 단독으로 두지 않고 글자를 함께 쓴다.
5. 한 화면에 주 버튼(accent 채움)은 하나. 나머지는 보조 버튼이나 글자 버튼.
6. 확인 대화상자 대신 바로 실행하고 되돌리기를 준다 (B안 원칙). 되돌릴 수 없는 일(발행, 삭제 확정)만 확인을 받는다.
7. 화면마다 빈 상태, 불러오는 중, 오류, 완료 표시가 있어야 한다. 비활성 버튼에는 왜 안 되는지 도움말을 단다.
8. 글자 대비 4.5:1 이상. tokens.css 값끼리 조합하면 지켜진다. 다른 색을 섞을 때만 잰다.

## 3. 컴포넌트 토큰 (같은 일 = 같은 방식)

시안에서 정한 방식이다. 새 기능이 나오면 `.claude/refs/UI_패턴_사전.md`에서 후보 2~3개를 비교해 고른 뒤 이 표에 한 줄 더한다.

| 하는 일 | 정한 방식 | 시안 근거 | Streamlit |
|---|---|---|---|
| 다음 일로 넘어가기 | 끝내면 다음 칸으로 ("기록하고 다음", "초안 완료 → 다음 초안") | B안, v2m 홈·이슈·진행 | 버튼 + 상태 이동 |
| 저장 | 자동 저장, 저장 버튼 없음 | v2b 이슈 | 위젯 `on_change` |
| 삭제·취소 | 바로 실행 + 되돌리기 | B안 | 알림(`st.toast`) + 되돌리기 버튼. 표에서 지운 줄은 **위젯 key 에 판 번호**를 붙여 되살린다 (설정 화면) |
| 목록 | 흰 카드 그룹 목록, 선택 행 왼쪽 파란 막대 | v2m | **`views/ui.py` `card_list()`** — `st.columns([9,2])` + 카드 HTML + 「열기」 버튼 (사전 §6 "목록 + 상세", 2026-11-13 S5에서 정함). 고르지 않는 카드 한 장은 `ui.card()` |
| 화면 안 자리 바꾸기 | 고르는 칸(`selectbox`) | — | 거르기가 아니라 **무엇을 볼지 옮기는 것**이라 칩을 쓰지 않는다 (설정의 표 15종) |
| 걸러 보기 | 칩 + 찾기 칸 | v2s 이슈 원장 | **`ui.filter_pills()` + `ui.search_box()`** — `st.pills` + `st.text_input`. 건수는 칩 안에 넣어 지표를 따로 두지 않는다 |
| 여러 건 처리 | 체크한 뒤 일괄 동작 | v2s 이슈 원장 | **`ui.check_list()`** — `st.data_editor` 체크 칸, 값 칸은 잠근다 |
| 순서 바꾸기 | 끌어서 놓기 | 스튜디오 | 기본 위젯에 없음 → 위·아래 버튼으로 대체할지 S7에서 정한다 |
| 바뀐 것 표시 | signal(주황) 표시 | v2s 회의 "발행 뒤 바뀐 장" | 상태 배지 |
| 근거 표시 | 노란 바탕(`--warn-soft`) | v2s 가져오기 | 표시 칸 |
| 날짜 고르기 | 미정 | — | 처음 쓰는 슬라이스에서 사전 2장으로 비교 |
