# 공개 데모 배포 — Streamlit Community Cloud

> **이 문서는 「보여 주기용 데모」에 대한 것이다.** 실제 운영은 **사내망**이고 그 길은 `ROADMAP.md` P5 다.
> 공개 호스트에는 **가상 데이터만** 올라간다 (`CLAUDE.md` §6-9).

## Vercel 은 안 된다

Vercel 의 Python 런타임은 **서버리스 함수**를 기대한다 — `app.py` 에 `app`·`application`·`handler`
같은 WSGI/ASGI 객체가 있어야 한다. Streamlit 은 **살아 있는 서버 프로세스**로 돌면서
누를 때마다 스크립트를 처음부터 다시 도는 물건이라 내보낼 객체가 없다. 억지로 만들어 붙여도 돌지 않는다.
게다가 이 앱은 SQLite 파일에 쓰는데 서버리스는 요청 사이에 파일이 남지 않는다.

```
Error: [PYTHON_ENTRYPOINT_NOT_FOUND] Found app.py but it does not export
a top-level "app", "application", or "handler" variable.
```

→ **저장소에 붙은 Vercel 프로젝트를 지우거나 Git 연동을 끈다.** push 마다 실패 빌드가 돈다.
저장소 안에는 `vercel.json` 도 `.vercel` 도 없다 — 연결은 Vercel 대시보드 쪽에 있다.

## 되는 것 — Streamlit Community Cloud

준비는 **이미 돼 있다.**

| | |
|---|---|
| `requirements.txt` | 뿌리에 있다. pip 로 깔리는 목록이고 정본(`pyproject.toml`)과 같다 |
| `.streamlit/config.toml` | 테마·정적 파일 제공(`enableStaticServing`) 설정 |
| 기준정보 | `data/samples/masters/*.csv` 15종 99행이 저장소에 들어 있다 |
| 첫 실행 시드 | `app.py` 의 `_first_run()` 이 **빈 DB 일 때만** 적재한다 |

### 올리는 순서

1. https://share.streamlit.io 에 **저장소 주인 계정**으로 들어간다
2. 「New app」 → 저장소 `kuku5417-wq/meeting_v`, 브랜치 `main`, 파일 **`app.py`**
3. Deploy

끝이다. **배포 버튼은 사람이 눌러야 한다** — 계정과 저장소 권한이 걸려 있다.

### 데모에서 안 되는 것

| 무엇 | 왜 |
|---|---|
| **AI 메모 정리 (F1)** | 사내 LLM 이 없다. 기록함은 **직접 적기**로 떨어진다 (사외망과 같은 동작) |
| **실데이터** | 호선·장비·이슈가 전부 **가상**이다. 실제 회사 메모는 넣지 않는다 |
| **저장이 남는 것** | 컨테이너가 다시 뜨면 `data/meeting.db` 가 날아간다. 적은 이슈·회의자료도 함께 사라진다. **기준정보는 첫 실행 시드로 다시 찬다** |
| 사진 마킹 | `streamlit_drawable_canvas` 를 깔지 않았다 — 좌표 수동 입력으로 강등된다 |

마지막 줄이 데모의 성격을 정한다 — **보여 주는 용도이지 써 보는 용도가 아니다.**
사람들이 넣은 것이 남아야 하면 사내망(P5)이거나, 파일이 남는 호스트(컨테이너 + 볼륨)로 가야 한다.

## 사내망으로 갈 때 (P5)

공개 데모와 **다른 길**이다. 바뀌는 곳은 네 군데뿐이다 (`CLAUDE.md` §3).

- `config/paths.py` — DB 경로
- `modules/sn_util.py` — 호선번호 규칙
- `modules/llm_client.py` — 사내 LLM 창구
- `modules/milestone.py` `_read()` — 일정 미러 (CSV → parquet)

기준정보는 **CSV 만 바꿔 끼운다** — 표 이름·칸 이름·칸 순서가 고정이라(`SPEC.md` §9-A)
헤더 값만 맞으면 그대로 돈다.
